# Android 版（JR 西日本・個人用）

デスクトップ版を Android 向けに作り替えた個人用ビルドです。変更点は次のとおりです。

- 表示するプリセットは **JR 西日本（19 波）のみ**。
- 起動時は **チャンネル未選択**。「路線から選ぶ」か個別チェックで受信する波を選びます。
- 受信機材は **トグルで切替**：「この端末の SDR（OTG）」／「別機材（RTL-TCP）」。
- 受信中は画面を点灯したままにします（画面が消えると WebView の音声が止まるため）。

見た目や動作の切替は `ui/personal.js` の 1 行で決まります。このファイルを `index.html` から外すと、本家と同じ動作（3 社・全選択で開始）に戻ります。

## 入力の仕組み

SoapySDR は Android では使いません。入力は純 Rust の RTL-TCP のみです。

| トグル | 接続先 | 使い方 |
| --- | --- | --- |
| この端末の SDR（OTG） | `127.0.0.1`（ポート既定 1234） | 同じ端末で rtl_tcp ドライバーアプリを起動し、RTL-SDR を OTG 接続して待ち受けを開始する |
| 別機材（RTL-TCP） | 入力した IP アドレスとポート | Raspberry Pi などで動かしている `rtl_tcp` に接続する |

アプリ自身が USB の RTL-SDR を直接開くのではなく、ドライバーアプリ経由です。ドライバーアプリの待ち受けポートが 1234 と違う場合は、ポート欄を合わせてください。サンプルレートは既定の 240,000 S/s のままで使えます。

## APK の作り方

1. このリポジトリを自分の GitHub に fork（または push）します。
2. Actions タブ →「Android APK」→ Run workflow。ほとんどの現行スマホは `aarch64` です。
3. 完了した実行結果ページの Artifacts から `jr-west-radio-receiver-aarch64` をダウンロードし、中の APK を端末に転送してインストールします（「提供元不明のアプリ」の許可が必要）。

初回は Rust のビルドで 20〜40 分ほどかかります。

### 署名キーを固定する（任意）

既定では実行のたびに一時キーで署名するため、更新するときは先に古いアプリのアンインストールが必要です。上書きインストールしたい場合は、キーを 1 度作って Secrets に登録します。

```
keytool -genkeypair -keystore release.keystore -alias key0 -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.keystore   # macOS は base64 -i release.keystore
```

リポジトリの Settings → Secrets and variables → Actions に次の 3 つを登録します。キーファイルは公開しないでください。

- `ANDROID_KEYSTORE_BASE64`：上の base64 出力
- `ANDROID_KEYSTORE_PASSWORD`：キーストアのパスワード
- `ANDROID_KEY_ALIAS`：`key0`

## 使い方

1. ドライバーアプリで RTL-SDR を起動し、待ち受けを開始します。
2. アプリの「受信設定」で「この端末の SDR（OTG）」を選びます（Android では初回から選択済み）。
3. 「路線から選ぶ」で線区を選ぶか、チャンネル一覧でチェックを入れます。
4. 「受信を開始」を押します。

## 制限事項

- **実機での動作確認は未実施**です。作成環境に Android SDK/NDK がなく、APK のビルドも実行していません。UI の挙動は jsdom のテスト（79 件）で確認しています。最初のビルドで Gradle や Tauri の設定が合わない場合は、Actions のログを見て調整が必要です。
- 画面を消すと音声が止まる場合があります。常時動作させるにはフォアグラウンドサービス（Kotlin 側の実装）が別途必要で、今回は入れていません。
- 録音・保存先はアプリ専用の領域です。ファイルマネージャーからは直接見えません。
- 西日本の最大 19 波を同時に復調するため、端末によっては CPU 負荷が高くなります。重い場合は受信する波を絞ってください。
- IQ WAV ファイル入力と SoapySDR デバイス入力は Android では使えません。
